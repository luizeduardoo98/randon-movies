# 🎬 Random Movie Generator

A simple web app that generates a random movie when you click the button. Built using **HTML**, **Tailwind CSS**, and **JavaScript**.

> 🔸 This project is optimized for **mobile view only**.

## 📱 Demo (Mobile Version)

🎥 Watch the demo video: [movies-project.mp4](./movies-project.mp4)

## 🧩 Features

- Randomly generates a movie per category
- Categories included: **Drama**, **Mystery**, **Horror**
- Movie data is fetched from the **TMDb API**
- Simple and intuitive mobile layout

## 🛠️ Tech Stack

- HTML
- Tailwind CSS
- JavaScript
- [TMDb API](https://www.themoviedb.org/)
